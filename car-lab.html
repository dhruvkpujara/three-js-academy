MODEL WORKFLOW

Where Transformers.js fits

  1. Collect sensor readings and action labels here.
  2. Train a small steering policy in a training environment suited to numeric data.
  3. Export the trained model to ONNX, then use Transformers.js to run supported model inference in the browser.

Transformers.js is mainly for running models in the browser; it does not automatically train a new driving model from these samples. This lab exports clean JSON for the training step.
