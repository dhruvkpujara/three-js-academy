🧠 What you're learning

A Three.js scene is a small 3D world. We put objects inside it, point a camera at them, and ask the renderer to draw each frame.

🎚️ Experiment with the cube
💻 The important code
const scene = new THREE.Scene();

const camera = new THREE.PerspectiveCamera(...);

const geometry = new THREE.BoxGeometry(...);
const material = new THREE.MeshStandardMaterial(...);
const cube = new THREE.Mesh(geometry, material);

scene.add(cube);
renderer.render(scene, camera);

This tiny example uses the same building blocks we'll reuse in larger projects.

🔗 How this combines with old learning

These pieces never get thrown away. Later lessons will keep the scene and camera while adding lights, animation, interaction, models and physics.
