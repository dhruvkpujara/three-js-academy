CONCEPT

What is a 3D scene?

Think of a Three.js scene as a small 3D world. We place objects inside it, choose a camera, and use the renderer to draw the world.

EXPERIMENT

Move the cube

Change one value at a time and watch what happens.

CODE

What the code is doing

const scene = new THREE.Scene();

const camera =
  new THREE.PerspectiveCamera(...);

const geometry =
  new THREE.BoxGeometry(...);

const material =
  new THREE.MeshStandardMaterial(...);

const cube =
  new THREE.Mesh(geometry, material);

scene.add(cube);

renderer.render(scene, camera);

Don't memorize this yet. We'll understand every line one concept at a time.
