CONCEPT

Geometry is the shape

Geometry describes the vertices, faces and dimensions that make up a 3D object. The material controls how that geometry looks.

const geometry =
  new THREE.SphereGeometry(
    1.5, 32, 16
  );

const mesh =
  new THREE.Mesh(
    geometry,
    material
  );
